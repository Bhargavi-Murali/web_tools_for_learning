2D Harmonics and Hydrogen-Orbital Explorer

This Three.js page visualizes a hydrogen-like 2D wavefunction as a 3D surface. The horizontal plane represents the 2D space. The vertical height represents wave amplitude or probability density. This helps connect 2D harmonics, nodal lines, radial nodes, and orbital shapes.

This is a pedagogical hydrogen-like 2D model, not a strict exact solution of the 2D Coulomb problem. It is meant to make the nodal structure and angular harmonics visually clear.

Model used

ψ(r,θ) = Rn,m(r) Φm(θ),   Φm(θ) = cos(mθ) or sin(mθ)

The radial part is modeled using a hydrogen-like Laguerre form. For a given n and m, the number of radial nodes is approximately n − |m| − 1. The angular part creates nodal lines through the origin. Rotate the view to connect these 2D harmonic patterns with familiar orbital shapes.

Teaching tip: choose Probability density |ψ|² to compare with orbital pictures, and choose Animated standing oscillation to emphasize the wave interpretation.
